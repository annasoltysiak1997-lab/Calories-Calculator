# Bitewise — Calorie Calculator

Bitewise is a mobile calorie calculator designed to help users quickly check nutritional information and understand how the final result is calculated.

The project focuses on a clear information hierarchy, simple interactions and a calm visual language.

---

## 🎨 Branding & Design System

The visual identity was designed around the user's context and the main task of the application.

The branding combines a warm off-white background, Bite Blue as the main action color, Plus Jakarta Sans typography and simple food illustrations.

The design system is based on a 4 px spacing grid, consistent components, typography styles, colors and interaction states.

The goal was not only to create a visually consistent interface, but to make the user's task quick and easy to understand.
